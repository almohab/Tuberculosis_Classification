# Dataset Sources

The code in this repository was developed using chest X-ray data obtained from the following public dataset distributions.

## 1. Tuberculosis (TB) Chest X-ray Database

Rahman et al.

- Dataset page: https://www.kaggle.com/datasets/tawsifurrahman/tuberculosis-tb-chest-xray-dataset
- Paper DOI: https://doi.org/10.1109/ACCESS.2020.3031384

The Rahman database documents that it was assembled from multiple chest X-ray collections. In this project, the Rahman database was accessed through its Kaggle distribution rather than by independently downloading each underlying collection.

## 2. Dataset of Tuberculosis Chest X-rays Images

Saira Kiran and Ishrat Jabeen.

- Mendeley Data, Version 2: https://data.mendeley.com/datasets/8j2g3csprk/2
- DOI: https://doi.org/10.17632/8j2g3csprk.2

## Important

The datasets are not redistributed in this GitHub repository. Users should obtain them from the original public sources and comply with the terms shown on those source pages.
